# UI / UX Design Specification
# Matheus — Web Developer & System Builder

**Document:** UI_UX.md  
**Project:** Personal Portfolio  
**Owner:** Matheus  
**Version:** 1.0  
**Design Direction:** Modern Futuristic Developer Workspace

---

# 1. Design Vision

The portfolio should feel like entering the personal digital workspace of:

> **Matheus — Web Developer & System Builder**

The visual experience should combine:

- Developer workspace
- Terminal interface
- Modern portfolio
- Engineering dashboard
- Minimal futuristic UI
- Professional personal branding

The design should immediately communicate:

> Code. Systems. Infrastructure.

Primary brand message:

> **From Interface to Infrastructure.**

The website must feel technical and futuristic without becoming overly cyberpunk, gaming-oriented, or visually noisy.

---

# 2. Visual Reference Direction

Use the provided portfolio screenshot as the main visual inspiration.

Important characteristics to preserve:

- Dark navy background
- Centered hero composition
- Neon green accents
- Developer terminal visual
- Floating code editor
- Ambient purple/green glow
- Technology marquee
- Compact navigation
- Technical background pattern
- Strong developer identity
- Clean section separation

However:

> DO NOT copy the reference pixel-for-pixel.

The final design must feel original and specifically designed for Matheus.


- Hero

Usage:

- Alternate sections
- Navbar
- Footer

---

## Surface / Cards

```css
--surface-primary: #0B1220;
--surface-secondary: #0F172A;
```

Used for:

- Cards
- Terminal
- Project containers
- Technical panels

---

## Border

```css
--border-default: rgba(255, 255, 255, 0.08);
--border-hover: rgba(74, 222, 128, 0.45);
```


# 6. Accent Colors

## Bright Green


Allowed.

```text
Tech marquee
```

Use sparingly.

```text

Background particles
Floating objects
```

Performance takes priority over decorative animation.

# 58. Cursor

Default browser cursor should remain for most elements.

Pointer:

```text

links

```

---

# 59. Loading

Do NOT create a long loading screen.

The website should appear immediately.

If loading state is required:

```text

```

for a very short period only.

Prefer no loader.

---

# 60. Accessibility

Interactive elements must have visible focus states.

Example:

```css
outline: 2px solid #4ADE80;
outline-offset: 4px;
```

Do not remove outlines without replacement.

---

# 61. Reduced Motion

Respect:

```css
@media (prefers-reduced-motion: reduce)
```

Disable:

```text
marquee
typing animation
scroll reveal movement
ambient animation
```

Keep content immediately visible.

---

# 62. Performance Rules

Avoid:

- Background videos
- WebGL
- Three.js
- Large particle libraries
- Excessive backdrop blur
- Huge image assets
- Multiple animation libraries

Prefer:

```text
CSS
SVG
Framer Motion only when necessary
```

# 67. Design Anti-Patterns

DO NOT implement:

- Rainbow gradients
- Excessive glassmorphism
- Giant rounded cards
- Excessive blur
- Constant floating animation
- Heavy particle backgrounds
- Fake skill percentages
- Generic stock illustrations
- Excessive emojis
- Gaming HUD interfaces
- Matrix rain
- Fake hacking animations
- Huge custom cursor
- Auto-playing background videos

---

The website must clearly belong to:
